# Security policy

Please do not report security vulnerabilities in public issues or pull requests.

Report them privately through GitHub's **Report a vulnerability** button on this repository's **Security** tab (private
vulnerability reporting). Include what you found, how to reproduce it, and the impact you expect. We aim to acknowledge reports
within a week and will credit you in the fix unless you prefer otherwise.

Software Factory runs coding agents against your repositories and can merge pull requests, so we are especially interested in:
ways to make it merge or run something it should not, prompt injection through issues or PR content, leaks of tokens or local
paths, and command injection through copied commands (for example session resume commands).
